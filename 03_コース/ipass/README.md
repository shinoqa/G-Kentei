## エンジン v1.0.1（DS STUDY の app.js からの差分）

機能は足していない。v1 に残っていた DS検定の文言（「即答テキスト」「★1」「スキルチェックリスト ver.6」「年3回（3月・6月・11月）」、用語集の分野ボタン）を `COURSE.ui` と `TEXT_PARTS` から読むようにし、問題0問でも割り算で壊れないようにしただけ。

- `COURSE.ui` が無ければ v1 と同じ文言になる。**DS STUDY のファイル一式で v1 と v1.0.1 を比べ、23画面（全タブ・10問の回答・結果・テキスト・用語の絞り込み）の描画が完全一致**（2026-11-12、Playwright・390px幅）
- `ui.pct: true` で「90点」→「正答率90%」と表示（iパスでは正答率を点数と呼ばない：COURSE仕様 §2）
- DS STUDY のアーティファクトは変更していない。v1.0.1 を DS に戻すかはオーナー判断
