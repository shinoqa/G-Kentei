# TANKU STUDY の系譜と知見

> 調査日：2026-11-11。数値はすべて**実測**（公開中のファイルを機械的に数えた値）。
> 対象：このリポジトリの `index.html`、G STUDY DAILY（アーティファクト）、DS STUDY DAILY（アーティファクト）。

## 1. 3世代の流れ

```
v0  G検定 学習アプリ（このリポジトリ index.html, 2026-06）
    └ 単一HTML。マインドマップ → 用語解説 → 確認問題。進捗は「習得/未習得」の2択
          │ 「地図で全体を見る」型はできたが、毎日続ける仕組みと復習がない
          ▼
v1  G STUDY DAILY（アーティファクト, 〜2026-10/11, 101ファイル）
    └ 「毎日20問」＋間隔反復の復習＋講師チャット＋記録。資料（A3まとめ・手書きノート・年表・用語辞典）
          │ 機能は充実したが、G検定専用の作り（試験日・問題ファイル名がコードに直書き）
          ▼
v2  TANKU STUDY エンジン v1（DS STUDY DAILY, 2026-11-08, 12ファイル）
    └ 試験に依存するものをすべて window.COURSE から読む「共通エンジン」。DS検定が最初のコース
          │
          ▼
次  ITパスポート ＝ エンジン v1 の2本目のコース（本PJTの対象）
```

**結論：共通エンジン化はすでに済んでいる。** iパスの仕事の大半は「コース（データ）を作ること」。

## 3. エンジン v1 の仕組み（DS STUDY の app.js から）

```
course.js ─┬ COURSE（試験日・問題数・合格ライン・カテゴリ→章・出典の優先度・学習計画・AIの人物像）
           └ QUESTIONS（id, source, chapter, ref, term, prompt, options[4], correct, explanation）
text_*.js   TEXT_PARTS（節ごとの本文。「例｜」「ツボ｜」「仕事｜」の書式）
glossary_*  GLOSS（[用語, 別名, 節ID, 定義, たとえ, 役割]）← 本PJTの「3点セット」がすでに実装済み
syllabus.js SYLLABUS（公式項目を節IDにひも付け。文言は言い換え）
                 │
                 ▼
app.js（エンジン）
  出題順：出典の優先度ごとに章を混ぜる → 毎日 goal 問（session 問ずつ）
  記録　：db の data/users/<利用者ID>/<コースID> に1文書（利用者ごとに非公開）
  画面　：今日の学習／復習／テキスト／用語／記録（カテゴリ別の正答率）／設定
  質問　：sample で解説を作り、db の asks/<コースID>__<問題ID> に残す
```

## 4. うまくいったこと（継承する）

| 知見 | どこで分かったか |
|---|---|
| 「毎日20問・10問ずつ」の小さな単位で続く | v1 / v2 の daily 設定 |
| 間違えた問題は翌日、正解が続くほど間隔を広げる（1→1→3→7→14日）。試験前日を超えない | v1 engine.js |
| 市販テキスト・問題集の章末問題は**原文を写さず、同じ論点・同じ正解の筋で書き直す**。出典は `ref` で本の問題番号を引ける | v1 official.js / book.js、v2 course.js |
| 本番形式の模試は**アプリに取り込まず本で解く**（予行演習に取っておく） | v1 book.js、v2 plan.mockNote |
| シラバスの公式キーワードと既存問題を突き合わせ、**一度も出ていない語を補完問題で埋める** | v1 review.json / extra.js（80問） |
| 誤答の傾向から専用ドリルを作る（第6章「名前⇄特徴」の取り違え → 名前当てドリル） | v1 drill6.js |
| 用語は「定義・たとえ・役割（試験と仕事での使いどころ）」の3点 | v2 glossary |
| 本文の書式「例｜ツボ｜仕事｜」で、試験の要点と業務への置き換えを分けて書く | v2 text_*.js |

## 5. 課題・未確認（iパスで効いてくるもの）

| 項目 | 内容 | iパスへの影響 |
|---|---|---|

| 計算問題の型 | 4択＋解説で表せるが、途中式の見せ方は未検討 | 損益分岐点・稼働率・基数変換など |
| 原本の置き場所 | v1 のコメントに `~/Desktop/G検定2026/`、`build.py` 等の記載。v2 も course.json から生成している様子 | 本セッションからはローカルが見えず、**原本がどこにあるか未確認**（D-005） |
| v0（index.html）の扱い | 現行は v1/v2。v0 はこのリポジトリにだけ残る旧版 | 参考資料として保存。改修対象にしない |
| スキルハブ | course.skills に「スキルハブ設計書（Private/スキルハブ/）の7軸」への対応表あり | iパスの章も7軸に対応付けるかは別途（本PJTでは未確認） |
